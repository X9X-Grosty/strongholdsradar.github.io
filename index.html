Strongholds Radar is a subscription-based Discord radar bot that sends automated notifications to your private server. This also comes with a range of tools that pull infomation directly from the game servers. If a subscription is inactive, alerts stop.

View plans Support
Delivery is through Discord. Payments are handled by Stripe Or Paypal if contacted Directly. You will receive access after payment is confirmed and you provide the following; Discord Server Link, In game House, In game world.

How it works

  • You subscribe and receive access for your server.
  • Your radar source posts to the specified channel.
  • You will have a category of channels reccomended you can either ask me to create or link to existing channels
  • If payment fails or is canceled, alerts stop automatically.

Use cases

  • Attacks / monks / scouts alerts with exact Troop counts notifications
  • In game Info such as; Catapult live radar, Village ID info searchup, Pairsh Gold lookups, Player Activity lookup, Village timing calculator, Radar filters.
  • Almost Instant results, Filtered to what you wish
  • Paying for multiple Houses (Multiple Servers) will increase the speed of commands

Features

Built for reliability.

Subscription gating

Alerts are blocked before enqueue and again before send, so inactive subscriptions cannot post but recent radar pings will process once paid if were held and recent.

Rate-safe delivery

Queued sending and pacing so your Discord channels don’t get nuked by spikes.

Multi-client routing

Each connection to game server maps to its own server. One bot can serve multiple customers cleanly.
